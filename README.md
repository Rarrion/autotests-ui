# autotests-ui

Учебный проект по автоматизации UI-тестирования на Python и Playwright.

Курс: «Автоматизация тестирования UI с Python и Playwright. Расширенный».

## Стек

- Python
- Playwright
- pytest

## Запуск

```bash
# создание и активация виртуального окружения
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # macOS / Linux

# установка зависимостей
pip install -r requirements.txt

# запуск тестов
pytest
```

## Структура

Проект наполняется по мере прохождения курса.
